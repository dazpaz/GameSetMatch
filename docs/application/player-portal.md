# Player Portal
The player portal is used by players to:

- Apply to be a player on the tour
- Accept application approval and set-up their profile
- Login to the player portal
- Logout from the player portal
- See their own home page
- View list of tournaments and the entry status to each
- View list of events they are entered into
- Accept an invitation to an event
- Apply to participate in an event
- View their upcoming matches
- Withdraw from a match
- See list of notifications / messages
- See their ranking and ranking history
- See their match history
- Manage their own profile
- Retire from the tour
